About Me

What I Am Exploring

  • Building and testing Go web applications.
  • Creating Docker images and pushing them through CI/CD pipelines.
  • Deploying applications on Kubernetes with clean manifests and Helm charts.
  • Using Argo CD to practice GitOps and keep deployments synced from Git.

Why This Project Exists

This website is my hands-on DevOps playground. Every page, workflow, chart, and deployment helps me understand how modern software delivery works in practice. The goal is to keep improving, keep shipping, and keep learning from every error message along the way.

About This Project

This project is a simple Go web application that serves static pages for Home, About, Contact, and Courses. Behind the scenes, it is also a complete DevOps practice project.

  • The app is written in Go and runs on port 8080.
  • A Dockerfile builds the app into a container image.
  • GitHub Actions builds, tests, and pushes the image to Docker Hub.
  • Kubernetes manifests and Helm charts deploy the app to a cluster.
  • Argo CD can sync the Helm chart from Git and keep the deployment updated.
